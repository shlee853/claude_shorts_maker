# 시장 급변 이슈 텔레그램 알림 봇 — 구현 계획서

작성일: 2026-10-07

## 1. 배경과 목표

### 문제
- 전쟁, 트럼프 발언, 관세·연준 관련 뉴스가 나오면 BTC·ETH와 주식이 급락한다.
- 뉴스를 직접 보고 대응하면 이미 늦다. 가격은 보통 수 분 안에 반응한다.

### 목표
1. **빠른 감지**: 시장에 영향을 줄 만한 발언이나 뉴스를 몇 초~1분 안에 포착한다.
2. **관련성 필터링**: 내 보유 자산(BTC, ETH, 보유 주식)에 영향이 있는 것만 보낸다.
3. **판단 가능한 알림**: "무슨 일이고, 어느 자산에, 어느 방향으로 영향을 줄 수 있는지"를 한국어 2~3줄로 전달한다.
4. **급락 원인 역추적**: 가격이 급락하면 직전 뉴스를 묶어 "원인 후보"를 보낸다.

### 비목표 (1차 범위 밖)
- 자동 매매. 오탐 한 번이 곧 손실이므로, 알림과 판단 보조까지만 한다.
- 가격 예측. 이 봇은 투자 조언이 아니라 정보 전달 도구다.

## 2. 핵심 설계 원칙

| 원칙 | 내용 |
|---|---|
| 속도 우선 | 폴링 주기가 곧 지연 시간이다. 핵심 소스는 10~30초 주기, 가격은 WebSocket으로 받는다. |
| 2단 필터 | 값싼 키워드 필터로 먼저 거르고, 통과한 것만 LLM으로 분류한다. 비용과 지연을 줄인다. |
| 알림 피로 방지 | 중복 제거, 같은 이슈 묶기, 심각도 임계값, 야간 정책을 둔다. 알림이 너무 많으면 결국 끄게 된다. |
| 소스 이중화 | 트윗·Truth Social 접근은 불안정하다. 단일 소스에 의존하지 않는다. |
| 사실과 추정 분리 | 원문 인용과 LLM 해석을 구분해 표시한다. |

## 3. 시스템 아키텍처

```
[수집기 Collectors]                      [처리]                         [전달]
 Truth Social (트럼프)  ─┐
 X(트위터) 주요 계정    ─┤
 뉴스 RSS/API           ─┼─▶ 정규화 ─▶ 중복제거 ─▶ 키워드 1차필터 ─▶ LLM 분류·요약 ─▶ 스코어링 ─▶ 텔레그램
 경제지표 캘린더        ─┤                 (SQLite)                    (Claude Haiku)                 │
 정부/연준 공식 피드    ─┤                                                                          └▶ 알림 이력 저장
 가격 스트림(BTC/ETH/주식)┘──▶ 급락 감지기 ──▶ 직전 뉴스 묶음 조회 ──▶ "급락 원인 후보" 알림
```

### 구성요소
1. **Collectors**: 소스별 비동기 수집기. 공통 인터페이스 `fetch() -> list[RawItem]`.
2. **Normalizer**: `{id, source, author, text, url, published_at, fetched_at}`로 통일한다.
3. **Dedup**: URL, 텍스트 해시, 유사도(임베딩 또는 shingle)로 같은 사건의 중복 보도를 하나로 묶는다.
4. **Prefilter**: 워치리스트 키워드와 계정 화이트리스트 매칭. 통과하지 못하면 LLM에 보내지 않는다.
5. **Classifier (LLM)**: 구조화 JSON을 출력한다. 아래 4.3 참고.
6. **Scorer**: LLM 점수에 소스 신뢰도, 계정 가중치, 보유 자산 관련도를 곱해 최종 심각도를 정한다.
7. **Notifier**: 텔레그램 전송. 심각도별 포맷, 쓰로틀링, 인라인 버튼을 지원한다.
8. **Price Watcher**: 급락·급등 감지기. 단독 알림도 보내고, 뉴스와 연결도 한다.
9. **Store**: SQLite. 수집 원문, 분류 결과, 전송 이력, 설정을 저장한다.

## 4. 상세 설계

### 4.1 데이터 소스

| 구분 | 소스 | 방식 | 비고 |
|---|---|---|---|
| 트럼프 발언 | Truth Social 게시물 | 공개 미러 RSS 또는 스크레이핑 | 공식 API가 없고 구조가 자주 바뀐다. 가장 중요한 소스이므로 미러 2곳 이상으로 이중화한다. |
| 유명인 트윗 | X API 또는 서드파티 API | 계정 목록 폴링 | X API는 유료이고 읽기 한도가 낮다. 서드파티(twitterapi.io 등) 비용 비교 후 결정한다. Nitter류는 불안정해서 보조로만 쓴다. |
| 속보 뉴스 | Reuters, AP, CNBC, Bloomberg 등 RSS, Google News RSS | RSS 폴링 | 무료. 지연이 수십 초~수 분 있다. |
| 이벤트 DB | GDELT | API | 전쟁·분쟁 이벤트 감지 보조. |
| 거시 공식 | 연준(FOMC 성명, 연설), 미 재무부, 백악관 브리핑, BLS | RSS/스크랩 | CPI·FOMC·고용지표는 발표 시각을 미리 안다. |
| 경제 캘린더 | Finnhub 또는 FRED/TradingEconomics | API | 발표 직전 "예고 알림"과 발표 직후 "결과 vs 예상" 알림. |
| 암호화폐 | Binance WebSocket(가격), Whale Alert(대량 이체), 거래소 공지 | WS/API | ETF 자금 흐름, 청산 규모는 2차 범위. |
| 주식 | Finnhub 뉴스/가격, Alpaca, 보유 종목 SEC 공시(EDGAR RSS) | API | 보유 종목 개별 뉴스는 티커 단위로 구독한다. |

**주의**: 소스의 이용약관과 스크레이핑 허용 여부를 구현 전에 확인한다. 유료 API는 월 비용 상한을 정한다.

### 4.2 워치리스트 설정 (`config.yaml`)

```yaml
assets:
  crypto: [BTC, ETH]
  stocks: [NVDA, TSLA]        # 사용자 보유 종목으로 교체
accounts:                      # 가중치: 1.0 최고
  - {name: realDonaldTrump, platform: truthsocial, weight: 1.0}
  - {name: elonmusk,        platform: x,           weight: 0.7}
  - {name: federalreserve,  platform: x,           weight: 0.9}
keywords:
  geopolitics: [war, missile, strike, invasion, sanctions, 전쟁, 미사일, 제재, Iran, Israel, Taiwan, Russia]
  macro: [tariff, rate cut, rate hike, FOMC, CPI, recession, shutdown, 관세, 금리]
  crypto: [bitcoin, ETF, SEC, ban, hack, stablecoin, 비트코인, 규제]
thresholds:
  push_min_severity: 3         # 1~5
  quiet_hours: "00:00-07:00"   # 이 시간엔 severity 5만 소리 알림
price_alert:
  drop_pct: {window_min: 5, btc: 2.0, eth: 3.0, stock: 3.0}
```

### 4.3 LLM 분류 (Claude Haiku 4.5, 빠르고 저렴한 모델)

입력은 원문, 작성자, 시각, 사용자 보유 자산이다. 출력은 JSON이다.

```json
{
  "relevant": true,
  "category": "geopolitics | tariff | monetary | regulation | crypto_specific | stock_specific | other",
  "affected": {"BTC": "bearish", "ETH": "bearish", "NVDA": "bearish", "SPX": "bearish"},
  "severity": 4,
  "confidence": 0.7,
  "summary_ko": "트럼프가 중국산 반도체에 추가 관세 50% 부과를 언급",
  "why_it_matters_ko": "반도체 공급망 우려로 NVDA 직접 타격, 위험자산 회피 가능",
  "is_new_info": true
}
```

- **프롬프트 원칙**: 방향성을 확정하지 말고 "가능성"으로 표현한다. 이미 알려진 내용의 재탕이면 `is_new_info=false`로 표시한다.
- **프롬프트 캐싱**: 시스템 프롬프트와 워치리스트는 고정이므로 캐시해서 지연과 비용을 줄인다.
- **실패 처리**: LLM 호출이 실패하거나 시간이 초과되면 키워드 규칙만으로 "원문 그대로" 알림을 보낸다. 분석이 없어도 알림이 누락되면 안 된다.
- **프롬프트 인젝션 방어**: 수집한 텍스트는 신뢰하지 않는 데이터다. 데이터 구역을 명시하고, 출력은 스키마 검증으로 제한하며, LLM에 도구 권한을 주지 않는다.

### 4.4 스코어링과 알림 정책

`final_severity = round(llm_severity × source_weight × asset_relevance)` 를 기본으로 한다.

| 심각도 | 의미 | 전달 방식 |
|---|---|---|
| 5 | 전쟁 발발, 대규모 관세 발표, 긴급 금리 결정 등 | 즉시, 소리 알림, 같은 이슈 후속 보도도 요약 |
| 4 | 트럼프의 시장 민감 발언, 예상 대비 큰 지표 이탈 | 즉시, 소리 알림 |
| 3 | 관련 있지만 영향 불확실 | 무음 알림 |
| 1~2 | 참고 | 저장만 하고 일일 요약에 포함 |

- **묶기**: 10분 안에 같은 이슈로 묶인 항목은 새 메시지 대신 기존 메시지를 수정하거나 스레드로 답한다.
- **쿨다운**: 같은 카테고리는 3분 안에 재알림하지 않는다. 단, 심각도가 올라가면 예외로 보낸다.
- **일일 요약**: 아침 8시 KST에 간밤 이슈, 오늘 경제 일정, 현재 시장 상태를 보낸다.

### 4.5 가격 급락 감지기 (이번 요청의 핵심 시나리오)

1. Binance WebSocket으로 BTC·ETH를 실시간 수신한다. 주식은 장중 Finnhub 또는 Alpaca를 쓴다.
2. 슬라이딩 윈도우(예: 5분)에서 낙폭이 임계값을 넘으면 트리거한다.
3. 트리거 시 직전 30분의 수집 항목을 심각도순으로 조회하고, LLM에 "이 급락의 원인 후보"를 요약시킨다.
4. 알림 예시:
   ```
   🔴 BTC 5분 -2.8% (97,200 → 94,500)
   원인 후보:
   1) 02:41 트럼프 Truth Social: "…" (심각도 4)
   2) 02:38 Reuters 속보: 중동 ○○ 공습 (심각도 4)
   ⚠ 인과관계는 추정입니다. 청산 연쇄일 수도 있습니다.
   ```
5. 원인 후보가 없으면 "뚜렷한 뉴스 없음, 청산·고래 이체 확인 권장"으로 표시한다.
6. 이 감지기는 뉴스 감지가 늦거나 놓쳤을 때의 **안전망** 역할도 한다.

### 4.6 텔레그램 메시지 포맷

```
🚨 [심각도 4] 지정학
트럼프, 이란 관련 "…(원문 인용)"
📌 요약: …
📉 영향: BTC↓ ETH↓ NVDA↓ (신뢰도 70%)
🕐 02:41 KST · 출처: Truth Social
[원문 보기] [30분 음소거] [이 유형 덜 받기]
```

- 인라인 버튼으로 음소거, 임계값 조정, 피드백(👍/👎)을 지원한다. 피드백은 이후 임계값과 프롬프트 튜닝에 쓴다.
- 명령어: `/status`, `/mute 30`, `/watch add TSLA`, `/threshold 3`, `/digest`, `/sources`.
- 허용된 `chat_id`만 응답한다.

## 5. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 언어 | Python 3.12 + asyncio | 비동기 수집, 풍부한 라이브러리 |
| HTTP/WS | httpx, websockets | 비동기 |
| 텔레그램 | python-telegram-bot 또는 aiogram | 인라인 버튼과 명령어 처리 |
| LLM | Anthropic API (Haiku 4.5 분류, 필요 시 상위 모델로 에스컬레이션) | 속도, 비용 |
| 저장소 | SQLite (이후 필요 시 Postgres) | 1인용, 운영 단순 |
| 스케줄링 | APScheduler 또는 asyncio 태스크 | |
| 배포 | Docker, 월 5달러 안팎 VPS(Fly.io, Hetzner 등) | **24시간 상시 구동 필요**. 노트북이나 임시 컨테이너는 부적합 |
| 설정/비밀 | `.env` + `config.yaml` | API 키는 저장소에 커밋하지 않는다. |
| 관측성 | 구조화 로그, 소스별 헬스체크 | 수집기가 조용히 죽는 것을 막는다. |

## 7. 테스트·검증 계획

- **단위 테스트**: 프리필터, 중복 제거, 스코어링, 쿨다운, 메시지 포맷.
- **회귀 샘플셋**: 과거 시장 충격 사례 20~30건(관세 발표, 중동 분쟁, FOMC 서프라이즈 등)을 고정 샘플로 저장하고, 분류 결과가 기대 심각도 범위에 드는지 확인한다.
- **리플레이 모드**: 과거 데이터를 시간순으로 흘려 보내 감지 시점과 알림 시점을 측정한다.
- **목표 지표**: 심각도 4 이상 알림 중 정밀도 70% 이상, 시장 급락 사건 중 알림이 선행하거나 동시 도달한 비율 80% 이상. 초기 목표이며 실측 후 조정한다.
- **장애 시나리오**: 소스 다운, LLM 타임아웃, 텔레그램 429(레이트리밋) 시 재시도와 큐잉이 동작하는지 확인한다.

## 8. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| Truth Social, X 접근 차단·구조 변경 | 핵심 소스 상실 | 이중화, 헬스체크, 뉴스 속보(사람들이 트럼프 발언을 인용 보도)로 보완 |
| 뉴스 지연 | 알림이 가격보다 늦음 | 가격 감지기를 안전망으로 두고, 공식 피드와 WebSocket 소스 우선 |
| 오탐 과다 | 알림 피로로 봇 무시 | 임계값, 묶기, 쿨다운, 피드백 학습 |
| LLM 오해석·환각 | 잘못된 방향 안내 | 원문 병기, "추정" 표기, 신뢰도 노출, 방향 확정 금지 |
| 프롬프트 인젝션 | 조작된 알림 | 스키마 검증, LLM에 도구 권한 없음, 화이트리스트 계정 |
| 비용 폭증 | 월 지출 초과 | 프리필터, 호출 상한, 캐싱, 일일 예산 초과 시 규칙 기반으로 전환 |
| 봇 다운 | 중요한 순간에 알림 없음 | 재시작 정책, 외부 워치독(heartbeat) 알림 |
| 비밀키 유출 | 계정·비용 피해 | `.env`와 시크릿 매니저, 저장소 커밋 금지, 텔레그램 `chat_id` 제한 |
