# 키워드 채점 가이드 (scoring v1)

이 문서는 GPT의 Knowledge 파일이다. `analyzeKeywords` 액션(프록시 서버)이 같은 공식으로 점수를 계산하며, GPT는 이 문서를 근거로 사용자에게 선정 기준을 설명한다.

## 1. 사용 지표

| 기호 | 지표 | 정의 | 수집 기간 |
|---|---|---|---|
| V | 월간 검색량 | PC + 모바일 검색 수 합계 (10 미만은 5로 간주) | 최근 30일 |
| Vg | 구글 월간 검색량 | 구글 검색량 (참고용, 점수에는 V가 없을 때만 사용) | 최근 1개월 |
| D | 누적 문서 수 | 해당 키워드로 검색되는 블로그 글 총수 | 누적 |
| R | 경쟁 비율 | D ÷ V (검색 1회당 경쟁 글 수) | - |
| G | 트렌드 증감률 | 최근 3개월 평균 검색 지수 ÷ 직전 3개월 평균 − 1 | 최근 12개월(지난달까지) |
| A | 상위 글 평균 경과일 | 정확도순 상위 10개 글의 게시일로부터 지난 일수 평균 | 조사일 기준 |
| F | 최근 30일 발행량 | 최신순 100개 글 중 30일 이내 게시 글 수 (최대 100) | 최근 30일 |
| C | 광고 경쟁도 | 낮음 / 중간 / 높음 (상업적 가치 참고용) | 최근 30일 |

## 2. 점수 공식 (총 100점)

`clamp(x, 0, 1)` = x를 0~1 사이로 자른 값

1. **수요 점수 (40점)** — 찾는 사람이 많은가
   `40 × clamp((log10(V) − 1) / 4)`
   - 10회 → 0점, 100회 → 10점, 1,000회 → 20점, 1만 회 → 30점, 10만 회 이상 → 40점

2. **경쟁 점수 (30점)** — 검색 수요 대비 글이 적은가 (수요·공급 비율)
   `30 × clamp(1 − (log10(R) − log10(0.5)) / 2)`
   - R ≤ 0.5 → 30점, R = 5 → 15점, R ≥ 50 → 0점

3. **트렌드 점수 (15점)** — 관심이 늘고 있는가
   `15 × clamp((G + 0.5) / 1.0)`
   - −50% 이하 → 0점, 0% → 7.5점, +50% 이상 → 15점
   - 데이터 없음 → 7.5점(중립)

4. **노출 기회 점수 (15점)** — 새 글이 상위에 들어갈 틈이 있는가
   - 신선도(8점): `8 × clamp((A − 30) / 335)` → 상위 글이 30일 이내면 0점, 1년 이상 묵은 글이면 8점
   - 발행 속도(7점): `7 × clamp(1 − (F − 10) / 90)` → 30일 발행 10건 이하면 7점, 100건이면 0점
   - 데이터 없음 → 각 항목 절반 점수

## 3. 등급

| 등급 | 총점 | 의미 |
|---|---|---|
| S | 80 이상 | 즉시 작성 추천. 수요 많고 경쟁 적음 |
| A | 65 ~ 79 | 우선 작성. 경쟁력 있는 키워드 |
| B | 50 ~ 64 | 보조 키워드·소제목으로 활용 |
| C | 35 ~ 49 | 롱테일로 묶어서 활용 |
| D | 35 미만 | 단독 공략 비추천 |

## 4. 정렬·선정 규칙

1. 총점 내림차순, 동점이면 V 큰 순
2. 50개 표는 1행 1~5위 … 10행 46~50위 (행 우선)
3. TOP 10은 상위 10개를 고르되, 검색 의도가 거의 같은(예: "캠핑의자 추천" / "캠핑의자 추천 순위") 키워드가 3개 이상이면 1개만 남기고 다음 순위로 대체
4. 일부 지표가 없는 키워드는 총점 뒤 `*` 표시

## 5. 검색 의도 분류

| 의도 | 신호 단어 | 추천 글 유형 |
|---|---|---|
| 정보형 | 방법, 뜻, 이유, 하는법, 종류 | 가이드·하우투 |
| 비교형 | 추천, 순위, 비교, vs, 장단점 | 리스트·비교 리뷰 |
| 구매형 | 가격, 최저가, 할인, 구매, 후기 | 제품 리뷰·구매 가이드 |
| 지역형 | 지역명, 근처, 맛집, 가볼만한곳 | 지역 정보·방문기 |

## 6. 지표 해석 팁 (사용자 설명용)

- 경쟁 비율 R이 1 미만이면 "검색하는 사람보다 글이 적은" 블루오션 신호다.
- 트렌드가 크게 오르는데 문서 수가 적다면 선점 기회다.
- 상위 글이 1년 이상 묵었다면 최신 정보로 쓴 글이 상위를 대체할 가능성이 높다.
- 광고 경쟁도가 높으면 상업적 가치(수익화 가능성)가 크지만, 같은 이유로 경쟁 블로그도 많다.
